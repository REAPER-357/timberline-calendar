How to set up Google Sheets sync
  1. Create a Google Sheet, then open Extensions › Apps Script.
  2. Delete the sample code, paste the script below, and save.
  3. Click Deploy › New deployment › Web app. Execute as Me, access Anyone. Deploy and authorise.
  4. Copy the /exec URL into the box above and tap Sync now.
